# Taller PHP

Aplicaciones web hechas con HTML, CSS, PHP y programación orientada a objetos (sin JavaScript).

1. Acrónimo de una frase
2. Sucesión de Fibonacci / factorial
3. Promedio, mediana y moda
4. Operaciones entre conjuntos
5. Decimal a binario
6. Árbol binario desde sus recorridos
7. Calculadora con historial

## Cómo ejecutarlo
1. Instalar XAMPP y encender Apache.
2. Copiar esta carpeta dentro de `htdocs` (por ejemplo `C:\xampp\htdocs\taller_php`).
3. Abrir `http://localhost/taller_php/` en el navegador.
